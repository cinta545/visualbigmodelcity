# 第四版-四个城市

版本：4.0.0；Git 标签：v4.0.0。

本版整合天津、长春、重庆、西安四城的三维展示改进。天津采用特色洋楼与统一的津门历史街区风貌；长春保留六处特色内容及森林街区；重庆重建夜景建筑、连续台地与下沉道路；西安采用宫殿、园林、塔院、商街四坊并延伸外围街区。

四城统一半透明数据面板和五个截图视角。全屏展示按钮收起分析面板、对象详情和视角栏。路口与外围道路按实际边缘作平滑连接，修正宽度和横向偏移，延伸段标线及人行道随道路连接。

道路、轨迹、原始灯态及车流事件保持真实数据来源；展示建筑、地标、景观设施和外围道路属于设计表现。西安信号灯方向未核实时保持未绑定。长春连接修正保留真实观测扫掠范围内的原有路面，不调整记录来适配模型。

## 运行与分发

运行 `npm ci`、`npm start`，访问 http://127.0.0.1:4173/ 。运行所需的处理后数据、设计布局、模型和材质已包含在仓库中。

包含代码、必要运行数据、测试、生成脚本、授权和说明文档。排除 node_modules、截图、下载分片、大体积原始 CSV、原始 TGA、临时镜头脚本、日志、数据库及本地环境配置。此前版本标签保留，不删除本机被忽略的资料。

布局重新生成需要 Python、Shapely 和对应来源数据；道路连接修正使用 `python scripts/prepare-road-alignment.py`。浏览器检查需安装 Chromium 并设置 `CHROMIUM_PATH`。
