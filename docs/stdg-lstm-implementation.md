# 论文轨迹预测实现

依据用户提供的《Multimodal Vehicle Trajectory Prediction with Spatio-temporal Dynamic Graphs and Importance Resampling》（20260812 Word稿）独立实现。没有作者代码或原始权重，不能称为论文结果复现。

## 已按论文采用的结构

输入为位置、速度、加速度和朝向七维状态，以目标车辆最后一个已知位置为原点、朝向为纵向轴。三秒历史输入共享嵌入与64维LSTM编码器。时间索引动态关系记录依赖边、关联边和关系创建/删除，离场邻居不进入当前空间网格。网格使用可学习偏移的3×3可变形卷积、3×1纵向卷积与非对称池化。128维LSTM解码器生成六组二维相关高斯序列及模态概率，逐步执行粒子初始化、转移概率权重更新、加权状态估计和重要性重采样。位置、二阶差分平滑、混合高斯负对数似然共同训练。

## 明确记录的实现选择

论文未给出完整构图、网格、模态、粒子和损失定义，这些由本实现选择。配置见 models/stdg-lstm/config.json：100毫秒步长，16个最近邻，纵向25格、横向9格，每格4米；30米关联范围，前方45米且横向3.5米内定义依赖边。边特征含相对位置、相对速度、关系类型及创建/删除标志。连续100毫秒采样隐含边更新时间间隔，历史门控权重聚合构图过程，当前掩码剔除失效关系。此构图不使用未核实的地图车道归属。超出网格的已选邻居汇入最近的边界单元，此项也是本实现的选择。

嵌入32维，六模态、64粒子，池化核为纵向1×横向2。位置和速度以50米、20米每秒归一化，加速度以10米每二次方秒归一化，朝向除以π。相邻观测最大间隔250毫秒，邻居新近性150毫秒。加速度只由已知历史速度差分计算。解码器以历史速度为运动先验并学习逐步位置增量；高斯标准差使用softplus及0.05米下界，相关系数限制于±0.95。平滑权重0.1、负对数似然权重0.05。粒子提议来自解码高斯增量，按预测高斯密度更新权重，每一步系统重采样；不增加有效粒子数阈值或重采样后扰动。随机种子由城市、车辆、观测锚点固定，回放结果可重复。

这些选择属于论文结构下的独立工程实现，不能当作论文作者未公开的参数。原文摘要和结果表的指标不一致，亦未给出完整图阈值，故不把原文数值写入本系统的实际评估结果。

## 训练和验证

使用四城SinD公开样例，目标预测为机动车，行人及非机动车可作为邻居。每城按整段场景时间划分70%训练、10%验证、20%测试；只保留完整历史和未来均位于同一分区的窗口，未来真值插值额外预留250毫秒，避免边界泄漏。同一车辆可以跨时间分区，因此这是场景时间留出协议，不是车辆身份留出或跨城市泛化测试。

Adam、学习率0.001、批量64，最多20轮，验证集ADE选择最佳权重并以五轮无改善早停。训练窗口两秒间隔；训练、验证和测试上限分别12000、2000、2000，固定种子抽取。测试集只在模型选择完成后访问。记录数据SHA256、权重SHA256、设备、训练轮次及每城样本数。

评估报告位于 models/stdg-lstm/report.json。概率加权高斯均值的ADE、FDE、1—5秒RMSE与minADE分开报告，恒速基线使用相同真值窗口。deployedParticleEstimate 单独记录网页实际展示的粒子加权估计ADE和FDE；moving/stationary分层按0.5米每秒区分，避免静止目标掩盖运动车辆误差。网页主线是粒子加权估计，薄线是解码器六个模态；两种输出不能混淆。尚不把模型候选概率作为事故概率，原有三秒包络风险计算保持原协议。

## 本轮实际结果（2026-10-09）

RTX 4060 Laptop CUDA训练20轮，以验证集选择第18轮。训练/验证/测试窗口为12000/2000/2000。五秒测试误差，单位米：

| 输出 | ADE | 五秒FDE |
| --- | ---: | ---: |
| 页面粒子加权估计 | 0.827 | 2.424 |
| 解码器概率加权均值 | 0.743 | 2.208 |
| 同窗口恒速基线 | 1.181 | 3.276 |

测试有601个运动窗口、1399个静止窗口。解码器在运动窗口的ADE为1.857米，恒速为3.323米；静止窗口分别0.264和0.261米。重庆子集解码器ADE为0.168米，恒速为0.130米，未改善。以上分层结果属于解码器，页面粒子估计目前单独报告总体指标。模型仍有长时预测误差，不能把六模态概率视为风险概率。

## 启动与重新训练

安装 research/requirements.txt 对应依赖（需与CUDA驱动兼容），执行 `python research/test_stdg.py` 和 `python research/train_stdg.py`。首次训练完成后运行 `npm start`；首次选择论文预测会启动127.0.0.1:4174上的只读推理进程。可用 STDG_PYTHON 指定Python可执行文件。输入仅接受城市、真实对象编号和回放时间，不接受调用者伪造未来轨迹。

首页与分析页仅保留论文模型，展示未来五秒及模态概率，已移除运动学预测与门控选择入口和实现。报告中的恒速数值仅用于训练评估参照，不作为页面预测方法。没有权重、历史不足或服务异常时明确显示原因，不以恒速输出冒充论文预测。
