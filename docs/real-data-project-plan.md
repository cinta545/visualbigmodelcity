# 真实交通三维研究与展示系统

## 当前状态

天津、长春、重庆、西安分别使用真实轨迹与信号数据，三维建筑及街区为展示性设计。首页交通统计、车型分布、进口流量、风险候选及对象交互已接入。

轨迹预测仅使用已训练的 STDG-LSTM：三秒历史、五秒未来、六模态与逐步粒子重采样。首页与分析页统一展示该方法，保留历史轨迹查看、五秒端点误差与预测表格导出。历史不足或推理异常直接说明原因，不切换为其他算法。旧运动学轨迹预测、门控选择、比较面板及生成脚本已移除。

模型结构、未公开参数的实现选择、四城时间划分协议及实际训练指标见 [论文模型说明](stdg-lstm-implementation.md)。完整训练报告为 models/stdg-lstm/report.json，权重为本地 checkpoint.pt。

## 数据和验证

原始观测坐标、速度、朝向和记录边界保持真实；未来真值只用于训练标签和离线评估，不进入推理输入。使用现有公开样例进行场景时间留出测试，完整数据仍需依官方要求申请，见 [数据获取记录](sind-data-access.md)。当前结果不代表跨城市或未见采集场景的泛化性能。

## 风险与复核

交叉冲突、追尾接近与慢行交互继续使用独立的三秒恒速矩形包络接触计算；这是风险候选核验模块，不能把模型候选概率解释为事故概率。事件筛选、片段播放、人工复核、备份恢复和阈值敏感性工具保留。协议见 [风险说明](sind-risk-baseline.md)。

## 后续研究

优先补充完整采集记录，建立独立场景与身份留出评估；分别审查运动与静止目标，重点诊断重庆子集与转向车辆。信号方向、地图约束和真实冲突标签须核实后再用于方法扩展。

## 运行

`npm start` 启动本地只读真实数据服务；`npm test` 验证功能。安装研究依赖后，`npm run sind:evaluate` 重新训练并生成报告。页面验证使用 `node scripts/check-paper-prediction.cjs` 与 `npm run home:check`。
