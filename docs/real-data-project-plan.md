## 前阶段：四城市探索性基线研究完成

## 前阶段：复核恢复、分类筛选与参数敏感性

固定 100 ms 扫描，对 TTC 上限 1/1.5/2/3 秒、合并间隔 100/300/500 ms 做 12 组比较。合并间隔 300 ms 时事件数依次为 26/64/120/305；TTC 上限 3 秒时，三种合并间隔对应 306/305/303 个事件。结果包含当前包络重叠核查项，不代表阈值优劣或准确率。该比较只覆盖这两个参数，没有验证采样率、尺寸假设或朝向阈值敏感性。

## 前阶段：事件合并与人工复核

新增整段离线事件索引。每 100 ms 计算风险候选，同一对象对的相邻命中间隔不超过 300 ms 时合并为一个事件；类别变化保留在类别历程中，较长中断分开。起止时刻为首次/末次命中，短暂空缺可以包含在区间内，并不意味着整个区间连续存在候选。此次 2,745 条对象对采样整理为 305 个候选事件；不是已确认的冲突或事故，也未做阈值敏感性分析。

首页“风险候选 → 事件复核与整段统计”提供事件列表、ID 与复核状态筛选、最小 TTC 时刻、前后 2 秒定位、带边界自动暂停的片段播放，以及待复核/保留/排除/无法判断和备注保存。复核仅存当前浏览器 localStorage，键含源数据 SHA256、方法版本、扫描与风险配置；可导出全部事件与复核 CSV。不会自动为用户生成真实判断，测试备注仅在临时浏览器测试上下文。

事件索引是整段离线检索，包括后续片段，已在界面标明，与逐时刻的因果风险候选分开。索引通过 `npm run sind:events` 生成，准备数据命令也会自动重建。19 项测试通过，包括合并边界、类别变化、分段、源文件哈希及 CSV 备注转义；浏览器验收见 `docs/visual-check/events-report.json`。

当前事件数量依赖采样步长与合并阈值，不提供经标注验证的精确率/召回率；下一步可完善复核结果导入、事件筛选统计与阈值敏感性分析，再推进正式研究评估。

## 前阶段：交叉冲突与追尾风险候选

首页新增“风险候选”标签：基于截至当前的最新观测，以恒速对齐到同一回放时刻，在 3 秒范围计算固定朝向矩形包络首次接触时间。车辆采用观测尺寸，行人使用明确标注的 0.6 米方形假设。按同向接近、交叉方向、弱势参与者交互、当前重叠和其他方向分类。

## 前阶段：3 秒预测基线与离线端点评估

首页已加入恒速 CV 和恒加速度 CA，支持 car、bus、truck、motorcycle、tricycle；行人与自行车暂不预测。黄色显示历史轨迹，蓝色显示预测轨迹，可独立关闭，并导出带模型、起点、时域、预测坐标及端点误差的 CSV。

预测只读取时间不晚于当前回放时刻的观测，以最新观测为起点，不调用用于回放的双向插值。最新观测超过 250 ms 则拒绝预测。CV 延续当前速度；CA 对过去最多 1 秒的速度分量做时间线性拟合，需至少 0.5 秒连续历史和 3 个采样，遇超过 250 ms 缺口截断。模型不使用车道、信号、交互或未来标签，可能外推到道路外，属于运动学比较基线。

评估独立读取未来真值，在预测起点后 1/2/3 秒计算欧氏端点误差。真值允许在相邻连续采样间插值；从起点至目标时刻存在超过 250 ms 缺口或目标超出观测区间则不评分。显示的是离线回看误差，不是实时可知置信度，也不是 ADE。

整段样例按每个对象至少间隔 1 秒取观测起点；各时域内 CV 和 CA 使用完全相同的有效起点。结果如下：

| 时域 | 有效起点数 | CV 平均端点误差 | CA 平均端点误差 |
| --- | ---: | ---: | ---: |
| 1 秒 | 9,589 | 0.252 m | 0.194 m |
| 2 秒 | 9,112 | 0.792 m | 0.628 m |
| 3 秒 | 8,635 | 1.531 m | 1.326 m |

这些是单个公开样例、包含静止车辆且按预测起点加权的描述性结果；没有训练，也没有独立泛化测试。不能据此声称模型达到完整数据集或真实部署性能。完整报告包含 P95，位于 `data/sind/baseline-evaluation.json`，运行 `node scripts/evaluate-sind-baselines.mjs` 可复现。

验证：15 项自动测试通过，包括修改或移除未来观测不改变预测、恒加速度解析轨迹、缺口和末端真值拒绝评分。2560×1440 浏览器验证两种模型切换、蓝线开关、行人不预测、31 点 CSV 与计算结果一致，无页面错误；截图及报告位于 `docs/visual-check/prediction.png` 和 `prediction-report.json`。复现 `node scripts/prediction-check.cjs`。

下一步为交叉冲突和追尾风险指标；交互预测、正式数据划分训练、数据诊断专页、视频导出与 RTX 4060 实机性能仍未完成。

## 运行与复现

`npm start` 启动 `server/observation-server.cjs`，默认 http://127.0.0.1:4173。

`npm run sind:prepare` 转换样例并运行场景审查。Python 依赖 pyproj 3.8.0 与 shapely 2.1.2。

## 验收与限制

已使用本机 Chromium 在 2560×1440 分辨率进行真实页面截图检查，检查总览、俯视、街角、街道近景，并修正了色彩偏白、默认镜头过近、近景树干遮挡、树叶块状轮廓、挡风玻璃被车身遮挡及缺少网页图标的问题。

斑马线从地图 inside/outside 边界生成，在两条边界共有的横向范围内绘制重复条纹，避免路口转角边界延长部分与相邻斑马线叠加。条纹宽度和间距属于渲染设计，不能作为测量标注使用。车辆公交显示牌取消了与真实数据无关的虚构线路名称。

浏览器检查通过：加载无页面错误、播放/暂停/拖动、2 倍速推进、点击观测车辆打开详情、X1 在 9.680 秒黄灯和 12.680 秒红灯、截图下载。检查结果在 `docs/visual-check/report.json`，四个视角截图也位于该目录。自动测试 10 项通过。

复现浏览器验收：`node scripts/visual-check.cjs`。使用本机已安装的 Chromium，路径可通过环境变量 `CHROMIUM_PATH` 指定；启动项默认指向当前安装的 Playwright Chromium 1228。浏览器依赖仅用于开发验收，不是产品运行依赖。

这些结果是无头 Chromium 的视觉和交互检查，不是 RTX 4060 的帧率基准。实际显卡性能、长时间播放资源占用仍需实测。街景与车辆仍有程序建模感，不能称为最终写实质量；不应在用户确认方向前扩建整个街区。

本轮视觉初稿仍需用户验收。录像导出、预测和风险模块尚未实现。
