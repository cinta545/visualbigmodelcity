# 第三版——长春

版本：3.0.0；Git 标签：v3.0.0。

本版在第二版四城真实交通可视化基础上，重构长春特色街区。保留伪满国务院旧址、地质宫博物馆、伪满皇宫博物院、苏军纪念塔、日月湾亭阁和 54 路复古电车六处内容，增加建筑材质、屋顶、窗框、入口及植被细节。

三栋主要建筑地块扩大至 36×30 米，模型宽度为上一版的 1.5 倍，竖向体量约为 1.68 倍。周边采用低层街屋，当前共有 156 个建筑/展品地块，去除各栋建筑独立的白色铺装边框，并以院落种植填充空隙。

电车高架横贯街区左右两侧，桥底高度约 6.55 米，22 个桥墩避开原道路和全部观测轨迹保护范围。电车保持静态展示，不生成虚构轨迹。长春展示道路统一双黄线、白色虚线及临近停止线的实线，消除原始地图与外围延伸道路的标线跳变。

建筑、高架与统一标线为展示设计，并非真实地理位置、测绘模型或工程结构设计。源轨迹、信号、流量事件不修改。

## 验证与复现

- 49 项自动测试通过。
- 四城市页面、五个视角缩略图、中文界面、流量及循环回放检查通过。
- 六处长春地标及街道近景渲染检查通过。
- 布局生成器针对全部 1411 条长春源轨迹检查地块及桥墩避让。

启动：`npm ci` 后运行 `npm start`，访问 http://127.0.0.1:4173/ 。运行数据已包含在仓库中。重新生成设计布局需 Python 与 Shapely，执行 `python scripts/prepare-changchun-quarter.py`。
