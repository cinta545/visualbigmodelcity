# 第二版（v2.0.0）

本版将四城真实交通回放与首页分析整合，并完成街区、车辆、人物及镜头显示细化。

## 主要变化

- 四城切换、真实轨迹循环播放、观测边界淡出及重庆长期静止车辆显示控制。
- 首页集成车型圆环、方向流量、趋势、风险与车辆预测。
- 细化商铺、道路铺装、街道设施与树木，加入授权人物及骑乘姿态。
- 增强汽车内饰、摩托车车壳及三轮车开放货厢，加入近远细节切换和平滑跟随。
- 镜头附近阴影聚焦；远处人物动作更新降频，观测位置仍逐帧更新。

## 精简与可运行性

分发保留处理后的四城样例和所需模型、贴图；排除依赖、下载缓存、原始大纹理、可重下原始 CSV、验收截图及日志。许可证与固定来源版本保留。本机原始文件不删除。旧提交未重写，因此旧版的大文件仍可能存在于 Git 历史；如只需运行第二版，下载此标签的源码压缩包或浅克隆即可。

安装启动：`npm ci`，然后 `npm start`，访问 http://127.0.0.1:4173/。

## 验证与边界

发布验证：精简快照独立安装依赖成功，47 项测试通过，四城浏览器加载检查通过且无缺失运行资源。第二版跟踪文件约 119 MB，较第一版约 499 MB 减少约 76%；必要轨迹数据保留。浏览器回归曾覆盖四城、轨迹边界、统计、预测及跟随。车辆远档几何数量检查不等价于整帧帧率基准。街区和模型是可视化设计，轨迹来自历史记录；风险与预测为研究基线。
