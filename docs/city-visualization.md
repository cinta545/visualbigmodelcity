# 四城数字可视化首页

## 页面与操作

- `/` 与 `/sind-3d.html`：天津、长春、重庆、西安独立场景；切换时保留各城回放位置。
- 历史记录自动循环，无进度条；暂停用于观察对象。每次循环重新统计本轮累计及最近六十秒通过量。
- 五张视角卡片直接截取当前三维渲染内容，点击后平滑切换镜头。
- 点击车辆或行人查看类型、编号、速度，可跟随观察；支持进口标识、保存画面和全屏。
- 首页两侧融合交通与风险图表：当前车型圆环、机动车行驶/低速状态、方向通过量、十秒分箱趋势、交叉/追尾/慢行交互候选。点选车辆可查看历史轨迹与未来三秒预测，并切换四种运动学模型；点击风险候选定位双方。
- “淡化静止车辆”仅调整画面透明度，不改变计数、流量、预测或风险输入；“跟随行驶车辆”定位当前速度不低于每秒零点五米的机动车。
- 点击车型圆环扇区或图例，可只显示对应类型，再次点击或选择“显示全部”恢复；图例支持键盘操作。统计保持完整观测口径，切换城市自动清除筛选。
- 风险定位会恢复全部类型，同时标出双方的当前包络、三秒恒速预测线和预计首次包络接触时的双方中心。候选失效、对象退出或主动取消时清理标记；这些标记不是实际碰撞认定。单车预测模型的切换不改变风险计算口径。
- `/analysis.html` 保留原来的轨迹、预测、风险、人工核验、导出和四城离线评估。分析页的三维对象检查仍为天津记录；四城评估可在报告选择器切换。

## 数据与展示边界

目前公开样例是四个城市各一段路口采集记录，不包含四座城市的完整路网或全城交通。标题使用已确认的城市名称，不推测具体路口名称。

原始道路、轨迹和时间戳保留。每城配置五十栋展示建筑、近景沿街商铺、行道树、照明及外围延伸道路。周边街区属于展示设计，并非测绘建筑复原；延伸道路不生成车辆。原始车道多边形另行保存，显示路面仅填平小型且没有路缘/护栏标记的内部车道拼接空隙。

展示建筑含周边五米范围避开地图道路、轨迹保守扫掠范围和延伸道路。车体按记录的长度、宽度缩放；没有观测的时间段不补造车辆运动。

建筑立面按住宅、商业与办公分型，增加底商玻璃、入口雨棚、阳台/竖向构件及屋顶收边。店前新增铺装带、树池、座椅和垃圾箱，均限制在原有建筑的五米审查余量内。外围人行道与路缘采用全部记录位置及车体保守半径计算避让距离，不延伸进真实观测范围。树冠使用实例化双面叶片，继续保持批量渲染。

默认总览镜头在多个方向和高度之间选择，避开建筑包围盒对路口中心及各进口端点的遮挡。显示建筑高度与镜头检查共用配置。批量渲染按每个面的材质组合分组，避免不同立面被错误合并。

轨迹覆盖边界由已记录位置估计，用于区分观测区域与展示街区，不代表精确传感器视野。车辆在连续观测段的开始和结束各最多七百毫秒内柔和淡入/淡出；短记录缩短过渡。超过二百五十毫秒的观测缺口分段处理，不连接缺口、不补行驶到展示道路尽头。淡出不修改坐标、速度、记录寿命或图表统计。

重庆车辆源文件共二十二万八千五百四十九行已与转换后的时间、位置、速度和朝向逐行核对，无差异。汽车类一百五十二条轨迹中有二十四条在各自记录全程的空间跨度不足一米，因此画面中大量车辆静止是样例内容。核对结果保存在 `data/sind/cities/chongqing-motion-audit.json`，不通过模拟运动改变这些记录。

## 流量定义

采用机动车类轨迹中心由外向路口内部穿越有限停止线段的事件，包含轿车、公交车、货车、摩托车、三轮车。行人和自行车仍参与场景播放，不计入此通过量。

相邻观测间隔超过二百五十毫秒不推断穿越；同一对象在同一进口只计一次。穿越时刻在相邻观测之间插值。最近六十秒窗口为 `(当前时刻−六十秒，当前时刻]`，累计只包含当前回放轮次已经发生的事件。回放开始不足六十秒时使用已有记录，不换算成小时流量。

## 信号

原始状态零为红、一为绿、三为黄，按最近已记录事件更新。尚无有效时间戳的区间显示“未记录”。车辆播放遵循真实轨迹，不用信号灯重新控制车辆。

天津四个三维灯杆已存在地图与灯组绑定，继续使用。其余城市暂以状态面板显示真实灯组；未核实灯组与灯杆对应关系之前，不任意绑定三维灯色。

## 生成与验证

执行 `npm run cities:prepare` 生成城市配置及通过事件；需要本机 Python 的 shapely、pyproj。执行 `npm start` 后，`npm run cities:check` 检查四城切换、截图卡片、中文首页、通过量、循环、黄灯与分析页，并在 `artifacts` 保存截图。浏览器路径可通过 `CHROMIUM_PATH` 指定。

`npm test` 包括通过事件与原始轨迹交点核验、时间窗口边界、循环计数，以及原有预测和风险回归测试。画面检查使用二千五百六十乘一千四百四十分辨率；浏览器截图验证不能代替目标设备的持续帧率测量。

`npm run home:check` 进一步检查首页图表、模型切换、淡化显示不改变统计、实际车辆材质淡出、坐标与观测一致、到期退出，以及重庆行驶车辆的实际位移。测试以只读浏览器快照观察渲染对象，不向生产页面暴露调试接口。

`npm run links:check` 检查圆环/图例筛选、键盘切换、统计不受筛选影响、跨城市重置、风险双方联动与取消/失效清理，并保存风险定位截图。

建筑镜头测试验证有限线段遮挡、四城路口端点可见性及多面材质实例合并的正确性。

当前为程序化街区展示模型，尚非摄影测量或照片级建筑资产。后续视觉精修可替换建筑外立面、树木和车辆资产，维持数据回放与统计模块不变。


### 天津车辆近景样板

天津轿车使用 `src/city-vehicles.mjs` 的精细程序化模型：独立轮拱、轮胎与五辐轮毂、刹车盘、曲面挡风玻璃、门缝、后视镜、前后灯罩及格栅。按材质合并静态零件，共享几何体，四个车轮保留独立旋转。天津精细轿车采用独立对象池，不会在城市切换后混入其他城市。

模型仍按记录长度、宽度缩放，位姿、淡出、计数与预测使用原始轨迹；灯具仅表示外观，不推断真实刹车或转向灯状态。车型外观是通用展示模型，不表示采集车辆的实际品牌和外观。当前天津样板覆盖轿车、公交和货车；其他城市仍使用原模型。公交增加乘客门、分段车窗、车顶空调、后视镜与重型轮毂；货车增加驾驶室、脚踏、货箱筋条、后门锁杆和挡泥板。货车高度按长度作有界比例调整，是外观估计，数据集没有提供实测车高。所有车辆的长度和宽度仍按记录缩放，外观选择不参与预测和风险计算。


### 天津光照与材质样板

天津使用晴天渐变天空与路口中心的静态立方体反射探针（256 像素每面，经 PMREM 预过滤），反射来自当前搭建的街区，不代表采集时的实拍环境。探针在该城市首次加载时生成并缓存，不逐帧重建。车辆轨迹参与者在采样时尚未显示，不会把车辆残影固定在玻璃反射中。

太阳阴影使用 4096 像素贴图；天津把阴影覆盖半径收至 105 米并减小法线偏移，以改善观测路口的接地细节。其他城市保留既有光照参数。道路继续使用现有已授权沥青纹理，在天津调整为两米重复尺度、降低颜色饱和度并增加轻微大尺度色差；色差仅为外观，不是实测路面病害或车辙数据。


### 重庆默认展示

重庆首次进入从真实记录 111 秒开始，之后仍循环完整记录，并在城市切换时保留播放位置。起播点根据机动车行驶数量选取，仅用于展示。满足记录跨度至少 30 秒、全段速度小于 0.5 m/s、全段位置包围盒对角线小于 1 米的汽车、公交和货车归为长期静止：当前样例共 22 条轨迹，111 秒时有 21 条在场。它们默认仅从三维视图隐藏，通过“显示长期静止车辆”可恢复；总量、流量、风险和预测输入不变。选中车辆或风险定位时，相关车辆仍显示。正常等灯后继续行驶的轨迹不符合该分类。全段分类不参与因果预测特征或风险判定。


### 重庆视觉升级

重庆已启用与天津一致的精细轿车、公交和货车、干燥沥青材质、晴天天空及阴影配置。环境反射在重庆街区内单独生成并缓存，切换城市时不复用天津的反射贴图。长期静止车辆显示开关、111 秒起播点、完整记录循环和统计口径保持不变。长春、西安仍使用原视觉配置。


### 四城统一视觉配置

天津、长春、重庆、西安现均启用精细车辆、干燥沥青、晴天天空与高精度阴影。每城独立生成并缓存街区环境反射；复用车辆几何体时仍按当前记录重新设置长度、宽度、颜色和轨迹。重庆保留独有的长期静止车辆开关与 111 秒默认起播点，其他城市不启用该筛选。车辆及信号数据、预测与统计口径保持不变。


### 行人与街道绿化细节

人物增加分段四肢、膝关节、鞋底及头部轮廓；自行车增加前叉、挡泥板、链条、脚踏及与踏板位置对应的腿部动画。步态、轮转与踏板只是根据观测位移生成的外观动画，不代表数据集实测姿态，不改变轨迹中心或风险输入。模型初次归一化使用实际几何顶点，避免旋转零件的粗略包围盒造成接地偏差。

四城街树增加分枝及不规则叶簇，每树约 650 片较小叶片，通过实例化批量绘制；不增加交通参与者。


### 天津写实人物资产样板

人物来源为 Microsoft Rocketbox 的 Male_Adult_01（MIT），使用原库 neutral walk 与 idle 骨骼动画。来源提交、文件哈希、材质转换说明记录于 `assets/characters/rocketbox/provenance.json`，原许可证完整保存在同目录。人物作为通用外观样板，不对应采集人员身份或外貌。仅天津行人与自行车骑行者启用，其他城市与摩托车、三轮车保留原模型。

FBX 中的灯光、相机被剔除，材质转换为当前 PBR 渲染配置，纹理缩至 1024 像素。使用 SkeletonUtils 克隆独立骨骼；原行走动画的水平根位移清零，依据观测位移设置步态相位。骑行者用双骨骼逆运动学匹配脚踏与车把目标，属于展示姿态而非观测真值。车辆和行人的根位置始终由 sampleTrack 决定。初始尺寸采用变形后的骨骼网格顶点计算，避免 A 姿势包围盒压缩人物比例。

验证：`node scripts/check-human-assets.cjs` 检查纹理、骨骼实例独立性、根位移移除、骑行手腕目标及有限几何；首页检查覆盖轨迹一致性、淡出和预测。头发和手部姿态仍可进一步精修，目前是单一角色样板。


### 四城人物样板推广

四城的行人及自行车骑行者均使用已授权 Rocketbox 人物，资源只加载一次，实例仍有独立骨骼。骑行姿态增加握把指节弯曲和脚掌方向约束；姿态按当前累计观测距离重建，暂停、回到同一时刻不会累积骨骼误差。城市切换继续复用对象池，重设每条记录的尺寸和位姿；重庆长期静止车辆显示设置保持不变。仍只有一种便装人物外观，摩托车及三轮车驾驶人尚未替换。


## 人物外观多样化（2026-10-03）

验证：两套模型各自检查骨骼独立性、重复姿态、根节点无位移、骑行手部目标及纹理加载；四城页面回归及近景截图复核。

普通建筑采用1.25倍目标尺度，四处特色建筑采用1.45倍高度和更大的横向目标尺度。横向尺寸按每个地块可用范围自动限制，最多向原地块外扩2米；生成脚本对原道路、延伸道路、677条真实轨迹扫掠范围及相邻地块进行检查。实际三维建筑包围盒再次由浏览器核对，50栋建筑均增大且保持在批准的展示地块内。

补充入口台阶、门廊、立柱帽、层叠檐口与阳台支撑；圆顶增加金属肋，民园中庭增加步道和规整绿植，瓷房子增加屋顶瓷饰小窗和瓷瓶，疙瘩楼增加阳台花槽。真实道路、信号和交通数据不变。

天津在原有四个核心建筑地块内加入民园广场、瓷房子、疙瘩楼和意式风情街建筑的展示性复刻。民园采用双层椭圆拱廊与连续环形楼板；瓷房子采用蓝白瓷饰、曲线栏饰和屋顶小窗；疙瘩楼采用红砖、石材角饰和多层阳台；意式建筑采用圆顶、拱窗和沿街露台。模型参考用户图片，缩放适配现有地块，并非实际地理坐标或精密测绘复原。

原50栋建筑全部改为统一的暖色石材、红砖、拱窗、檐口与红瓦坡屋顶，保留2—4层高差与少量圆顶变化。未修改道路、信号灯绑定或真实交通记录。52项测试通过，天津浏览器检查确认四处特色建筑、50个原地块、677条轨迹及4个原有信号灯模型，页面无错误；输出 artifacts/tianjin-heritage-*.png。

撤销西安独有的小图标视角栏与城市框布局，恢复统一的五张截图视角卡片。所有城市的玻璃面板统一为60%不透明的深色半透明背景，并使用12像素背景模糊。全屏展示模式同时隐藏数据分析面板、对象详情与底部截图视角栏，再次点击恢复；播放工具在收起模式下移至底部。

四城浏览器检查验证截图卡片、统一透明度和全屏收起/恢复功能，输出 artifacts/*-unified-panels.png。

四向主路沿原道路方向延续至900米，外围新增148米和244米位置的支路街网；新增道路仅作为场景展示，不增加车辆或统计事件。外围扩展至横向330米、纵向270米，布置190处低矮民居院落，形成连续城市肌理。四坊与中心真实路口维持原位置，新增建筑及道路避开真实轨迹扫掠范围。

外围民居采用三类简化院落与高差变化，使用统一材质批量合并；四坊保留近景细节。俯视镜头维持原尺度，通过补足外围而非缩小镜头遮掩空白。52项测试通过，浏览器检查总览、俯视和街角视角无报错。

背景院落从外围8处移为四坊背后的12处，增加低矮院落与小巷衔接，避开真实道路和轨迹扫掠保护范围。四个进口增加1.3倍显示比例的信号灯模型，位置根据原始停止线外缘放置并检查保护范围。

西安源数据有两组灯态事件，但公开地图未标注灯组方向，原场景 signalBindings 为空，因而过去未生成信号灯。新增模型仅为展示设施，stateUnbound 为真，灯头不伪造亮灯；两个真实灯组仍由原始事件驱动统计面板。对应方向需核验后才绑定三维灯头。初始无时间戳状态继续保持未知，不补虚构相位。

西安视角导航改为36像素高的小图标文字按钮，隐藏大幅预览图，使用轻半透明背景；五个视角功能保留。左上城市框缩至190像素宽，简化品牌标题与城市切换布局，左下播放工具同步缩小。路侧灯杆降低布置密度，小旗与招牌只保留间隔点位；四坊建筑布局和文化主题不继续扩张。浏览器复核总览、街角、俯视及面板收起功能，页面无错误。

靠近院墙的路侧绿植形成连续边带，生成时扣除入口通道以及真实道路、全部轨迹扫掠保护范围；树池配仿唐灯杆，花池配小旗与中文小招牌。宫廷区采用对称花池，池苑增加亲水坐凳与庭院灯，塔院增加内院矮墙，商圈增加茶点与手作小棚、货品及三辆停放自行车。

四坊共增加20位静态访客，复用已有授权人物模型，全部限制在展示街区内部；静态访客与停放自行车标记为场景装饰，不进入真实参与者对象表、车流统计或风险计算，也不生成虚构交通轨迹。

殿堂增加双扇门、铜环、门钉、柱脚与两层檐下木构；台基增加石材分缝，阶梯使用落地累积高度，避免薄片悬空。塔身增加拱券线脚；商铺增加条纹遮棚与木支杆；园林亭台增加木栏，柳树使用细分下垂叶簇。细节均限制在既有四坊范围内，不调整交通源数据。

西安道路采用独立青石贴图与浅浮雕接缝；交通线降低反差，斑马线采用浅石嵌条风格，原始几何、车辆轨迹和交通统计不变。其余城市沿用原道路与标线材质。

宫廷区增加轴线宫灯、铜鼎和祥云地面镶嵌；曲江池苑增加曲水流饮小景与题刻；大雁塔院增加雁塔题名碑；钟楼商圈增设四间临街店铺、中文匾额与货品陈列，留出中央门口通道。大雁塔保留为主要垂直地标，没有再叠加鼓楼或大型城墙。

西安使用淡金日光与四处有限距离的局部暖灯，未增加模拟交通或人流。浏览器验证保留439条记录、四坊及主镜头，页面无错误；52项测试通过。

针对围墙与车行道之间的空带，将四坊外缘到路侧的地面连接为石板步行空间，保留真实道路形状。四坊朝主路的一侧开设十米宽侧门，入口通道预留八米宽无障碍空带。

步行空间增加22处树池、20处矮花坛和24处坐凳，采用木色与石色统一古风材质。设施布点避开原始439条轨迹的扫掠范围及道路保护范围，生成脚本进行相交检查；不增加或修改真实车辆轨迹。

验证：52项测试通过；西安浏览器检查确认四坊、439条轨迹及主镜头保留，页面错误为零，并输出总览、收起面板、街角和俯视截图。

### 天津近景建筑第三轮细节

### 四城路口与外围道路连接修正

外围原先使用停止线宽度直接生成矩形延伸道路，忽略观测边缘的横向偏移及宽度变化。新增 scripts/prepare-road-alignment.py，在原延伸起点前8米的真实道路横断面提取连续车行道边缘（排除分离的人行道），通过40米平滑过渡接入既有外围道路。结果独立保存于 data/sind/cities/road-alignment.json；真实 road、roadSurface、停止线、轨迹和车流事件均不重写。

长春有车辆记录超出地图车道轮廓，因此保留观测扫掠范围内旧路面，并以圆滑补面处理接缝。生成检查保证既有车辆扫掠范围不失去原有路面，新增路面不侵入建筑地块。延伸段标线沿过渡轮廓绘制，并排除真实道路上的重复覆盖；人行道沿实际延伸路面连续生成，取消按观测半径突然开始的矩形人行道和路缘。

四城浏览器检查验证16个过渡配置，保留天津677、长春1411、重庆230、西安439条轨迹，页面无错误。新增过渡端点、连续性与标线范围测试，53项测试通过。俯视截图位于 artifacts/*-road-alignment.png。

后续沿街细化：建筑入口增加木门分格、玻璃上窗与铜把手，意式建筑补咖啡店及书房橱窗、门框和花池；民园内院补坐凳与花池，瓷房子侧墙延续蓝白瓷饰。背景建筑按间隔分配中文小店面和百叶窗，保持统一风貌并减少完全重复的立面。本轮50栋建筑放大比例及预留范围检查全部通过，保留677条真实轨迹及4个灯组绑定，浏览器无错误，52项测试通过。

民园广场增加双层拱廊的实体拱间墙、柱头和屋顶栏饰，保留开放内院；瓷房子增加蓝白陶瓷花饰；疙瘩楼增加三层凸窗与石材窗檐；意式建筑增加条纹遮棚、支架、咖啡桌椅、杯具及中文店招。统一建筑原型增加拱窗分块石券、拱顶石和屋面瓦垄。

本轮维持上一轮的放大比例。浏览器验证50栋建筑全部位于预留地块范围内，677条真实轨迹和4个信号灯绑定保持原样，页面无错误；52项测试通过。四处近景截图更新于 artifacts/tianjin-heritage-0.png 至 tianjin-heritage-3.png。
