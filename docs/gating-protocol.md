# 第三轮：因果特征模型选择协议

目标：以仅使用过去状态的模型选择器，在 CV/CA/DCA/CTRV 中选择一个三秒预测；与固定 DCA 和仅在训练记录上选出的全局最佳固定模型比较。

本轮运行前固定深度 2、叶节点至少 200 个起点、候选阈值为训练特征的 20/40/60/80 百分位、分裂的训练加权误差改善至少 1%。不按留出记录结果更改这些参数。

输入仅含起点速度、过去最多 1 秒拟合的加速度模/纵向加速度、过去速度方向估计的转率绝对值、低速转率回退指示。没有城市 ID、轨迹 ID、未来状态、未来方向标签或误差作为输入特征。

树的训练目标为三秒 FDE 的加权和。训练权重先按记录等权，再按记录内对象等权，最后按该对象的起点等权。叶节点选择加权平均 FDE 最低的模型；未来真值只用于训练记录的损失标签。

四轮验证，每轮完整留出一个采集记录，特征阈值、树结构与叶节点选择均只在其余三个记录训练。三秒连续真值与全部四模型有效的起点参与评估。各模型与选择器在相同起点上比较。固定 DCA 为既有比较基线，同时报告在训练记录上选出的最佳固定模型。

这四个公开记录已经被前两轮探索，故此为开发期记录级交叉验证，不是全新外部测试。只有四个记录，不能以起点数作为独立样本数推断统计显著性。不得仅保留有改善的折或在失败后隐瞒结果。当前不改变首页默认模型或 CV 风险计算。
