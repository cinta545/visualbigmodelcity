# 研究数据与评估准备

当前登记天津、长春、重庆、西安四个公开记录，均标记 development。现阶段不声称独立测试集表现，不训练交互模型，不将人工风险候选复核视为事故真值。

当前比较已扩展为 CV/CA/DCA/CTRV，四模型共享有效起点，明细更新为 972,352 行。DCA 固定 τ=1 秒，CTRV 低速历史回退 CV，详见 four-baselines-protocol.md 与 four-baselines-results.md。下方天津 CV/CA 表为仍有效的子集结果。

## 数据登记与隔离

配置文件 `shared/research-datasets.json` 中每条记录包含唯一 id、转换后的 replay JSON 路径、采集分组 group 与 split（development/train/validation/test）。路径相对项目工作目录；暂只支持本项目六列轨迹格式，不自动解析其他原始 CSV 目录。

后续获得多时段数据后，应先核对采集日期、时段和是否重叠，再将相同采集会话/重叠片段设为同一 group。训练、验证、测试按组划分，禁止随机拆轨迹行或将同一会话的交互参与者分散至不同集合。登记器拒绝重复 ID/路径、重复文件内容及跨集合的同名 group；无法自动识别人为错误命名的重叠会话，需要数据清单核验。

只有 train/validation/test 均有记录才标记“已配置独立分组”，这仍不意味着完成训练、标签审查或验证了组间独立性。测试集应在数据充分后固定，不用测试结果选择模型参数。

## 当前评估协议

- 类型：car/bus/truck/motorcycle/tricycle；其余对象暂未作为预测目标。
- 每条轨迹按原始时间顺序选取至少间隔 1 秒的预测起点；CV/CA 在每个时域共享相同有效起点。
- CA 至少需 0.5 秒连续历史；未来缺失、超出观测期或出现超过 250 ms 缺口不评分，并按原因计数。
- 时域为 1/2/3 秒，未来网格间隔 100 ms。ADE 对未来网格的欧氏位置误差取平均，不含起点；FDE 是该时域最后一点误差。真值只用于评估，不进入预测。
- 同时报告按预测起点平均和先在对象内平均再按对象等权平均，避免长期停留对象贡献更多起点而掩盖短轨迹误差。
- 按类别及起点速度 ≥0.5 / <0.5 m/s 分层；低速不是整段静止或排队标签。各时域的有效样本集合可以不同。

当前 972,997 行、2,757 条轨迹通过有限值、时间严格递增、非行人尺寸与 ID 归属检查。生成 486,176 行“模型×时域×有效起点”误差明细。现有格式已由转换器排序，检查不代表原始标注完全准确，也未审查速度与坐标差分一致性。

## 天津单记录结果示例（四城市完整结果见 multicity-research-results.md）

开发样例全部目标、3 秒时域，CV 和 CA 均有 8,635 个有效起点、474 个对象：

| 口径 | CV ADE/FDE（米） | CA ADE/FDE（米） |
| --- | --- | --- |
| 按预测起点平均 | 0.577 / 1.531 | 0.479 / 1.326 |
| 按对象等权平均 | 1.342 / 3.614 | 1.016 / 2.819 |

两种口径差异明显，论文报告应保留口径和样本数，不能只展示较低的数字。当前没有独立泛化、统计显著性或事故识别准确率结论。

## 运行与产物

`npm run sind:evaluate` 使用默认清单；也可 `node scripts/evaluate-sind-research.mjs <config.json>` 使用其他登记清单。输出位置固定为 `data/sind/research-evaluation.json` 和 `research-errors.csv`，新运行会更新这两份派生报告。

报告保存每个数据文件 SHA256、配置、质量检查、各项排除/纳入数量、预测/时钟/评估代码哈希、类别与速度分层、P95 FDE 和对象等权均值。CSV 保存逐起点结果，便于复算，不修改原始数据。

首页“交通指标 → 研究评估报告（离线）”可切换集合、运动状态和平均口径，并下载 JSON 与 CSV。这些是整段报告，不随回放时钟变化。

26 项测试通过，包含组间泄漏拒绝、ADE 解析例、缺口排除、对象等权统计与有效样本会计检查；浏览器验证六组显示组合及报告下载。执行 `node scripts/research-check.cjs` 可复现。

## 仍需数据与决策

需要提供其他合法取得的 SinD 记录目录及其采集时段信息，才能核查独立分组并推进交互模型训练。完整数据的许可/获取渠道和目录结构应在接入时核验。额外三个城市公开样例已主动下载并纳入评估；用户正在申请完整数据。每城只有一个公开记录，完整数据接入和正式独立训练仍未完成。
