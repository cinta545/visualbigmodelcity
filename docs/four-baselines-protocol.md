# 第二轮探索实验：固定参数说明

本轮先确定实现和参数，再运行已有四城市公开样例；这不是预注册试验或独立测试，也不把这些已探索记录用作未见测试集。

比较 CV、CA、DCA（衰减加速度）和 CTRV（恒转率恒速）。共享 CA 所需的至少 0.5 秒、最多 1 秒连续历史和相同未来真值有效起点。预测未来 3 秒，仍评估 1/2/3 秒，步长 100 ms。

DCA 沿用 CA 的速度线性拟合加速度 a0，假设 a(t)=a0 exp(−t/τ)，固定 τ=1 秒。位移为 v0 t + a0 τ[t−τ(1−exp(−t/τ))]。不按城市调参，不截断困难样本，也不约束车道或防止速度反向。

CTRV 将过去速度方向展开到连续角度，用时间线性拟合估计角速度，保持起点速度模不变并解析积分圆弧。历史任一速度模小于 0.5 m/s 时，方向不稳定，回退 CV 并记录回退次数。接近零转率时使用直线极限。没有转率上限、地图约束或交互响应。

所有历史值来自当前及过去；未来方向变化标签仅用于事后分层。报告同时比较按起点平均、按对象等权、各城市、运动状态、P95 与大误差案例。不能只选表现最好的一项并将其称为普适改进。

当前风险模块继续使用固定朝向 CV 包络，不将新模型预测线误称为风险计算依据。
