# SinD 公开样例接入：第一阶段

## 修复：首页功能保留

首页现在提供统一功能导航，默认打开 `sind-3d.html` 三维回放；总览、运行、对象、告警、预测、调度、诊断均可从首页切换打开。旧首页完整恢复为 `workspace.html`，保留其原有前端、API、Socket.IO、筛选搜索与控制操作。两页通过独立嵌入视图保留状态，首次打开工作台才加载。

这是恢复功能入口与原业务行为，不代表旧分析模块已使用 SinD：导航明确标记“本地仿真数据”，原调度只影响原仿真引擎，不能修改历史观测。后续需逐模块接入 SinD 状态、预测和风险计算；不能把旧仿真结果直接显示为真实数据结果。首页的浏览器交互与视觉尚待实测。

## 更新：首页直接显示三维回放

首页 `/` 已改为 `src/sind-home.mjs` 驱动的 Three.js 真实数据回放，不再加载旧仿真前端或其 Socket.IO 状态。`/sind.html` 保留为二维地图核对工具。旧首页备份在 `docs/index-before-sind-home.html`。

三维道路由 Lanelet2 左右边界生成，轨迹坐标映射为 `(x, 0, -y)`，车辆朝向映射为绕 Y 轴旋转 yaw，汽车/公交/货车按观测长宽缩放。行人、两轮车和三轮车使用简化示意模型，尚未达到最终写实质量。

地图明确给出名为 Traffic light 2/4/6/8 的四条灯位线段，本次按名称绑定对应灯色。灯杆高度和灯头外观为建模参数，并非现场测量；其余四组不推断空间位置，仅显示状态面板。首页支持自动播放、暂停、回放拖动、倍速、总览/俯视/街道视角与对象点击。不存在用随机车辆填充轨迹的行为。

前端语法检查和数据/回放自动测试通过；浏览器视觉与性能仍待实测。下文为前一阶段记录，其中首页仍为仿真的描述已经被本节替代。

已将官方天津 8_2_1 样例转换为本项目可读取的历史回放数据。

- 入口：`/sind.html`，首页标题下提供链接。
- 原始来源：https://github.com/SOTIF-AVLab/SinD
- 固定版本：930e4dea78d924c6e9a58ff8e378331f93bba8ec。
- 原始车辆/行人 CSV 共 166,065 行，677 条参与者轨迹，约 1,201.6 秒。
- 268 辆轿车、4 辆公交、4 辆货车、171 辆摩托、131 辆自行车、33 辆三轮车、66 名行人。
- 122 条灯色事件，包含零时刻之前的初始灯色；不使用下一条事件提前改变当前灯色。
- 原始文件 SHA256 与官方 Git LFS 指针一致，下载不完整时禁止转换。
- 本地审查结果：`data/sind/audit.json`；转换结果：`data/sind/replay.json`。

## 当前行为

等比例二维车道地图、按原始朝向和尺寸绘制车辆、行人点位、过去三秒轨迹、播放/暂停、拖动时间轴、0.5/1/2/4 倍速、X1–X8 灯色。

地图转换与官方可视化参考保持一致：WGS84 UTM 31N 投影，减去 (0,0) 的投影坐标。车辆位置为包围盒中心，单位米；时间为毫秒。显示时仅翻转屏幕 Y 轴，不更改原始交通几何。

回放仅在每个对象的观测生命期内插值，超过 250 ms 的数据缺口不连接，不生成离场后的车辆。角度使用最短角插值。信号始终采用当前时刻最后一条已知记录。当前采用已平滑的官方轨迹，后续做预测时必须审查平滑处理是否引入未来信息。

## 尚未完成

这是数据验证页，不是最终三维写实场景。首页现有虚构街区仍是本地仿真，不能称为 SinD 数字孪生。X1–X8 与实体灯杆、受控进口和车道的绑定尚待核验，当前不猜测绑定。

下一阶段：核验地图/轨迹叠合与信号灯空间对应，按真实路口几何调整三维道路；随后实现仅用历史信息的恒速/恒加速度预测基线及冲突风险指标。正式模型需完整数据与独立评估，不能使用未来真实轨迹作为预测，也不能将启发式风险分数称为事故概率。

## 复现

运行环境：Node >=22.5；Python 3；转换依赖 `pyproj==3.8.0`。

首次需要从上述固定版本取得 `Data/Tianjin` 下地图、信号和元数据文件，以及仓库 LICENSE、Format.md。现已存于 `data/sind-source`。大体积轨迹可通过 `npm run sind:download` 下载，具备分块缓存和整体哈希验证。

依次运行 `npm run sind:prepare`、`npm test`、`npm start`，访问 `/sind.html`。测试覆盖时间插值、生命周期、缺口、角度跨越 ±π、灯色切换边界，以及完整样例的行数和标识一致性。

浏览器画面和控件交互尚未完成本轮人工视觉验收。
