# 城市交通数字可视化系统 · 第三版——长春

版本 **3.0.0**，Git 标签 **v3.0.0**。基于 SinD 天津、长春、重庆、西安公开样例，提供真实轨迹循环回放、三维街区和首页交通分析。

## 启动

需要 Node.js 22.5 或更新版本。

```bash
npm ci
npm start
```

打开 http://127.0.0.1:4173/ 。仓库已包含运行所需的处理后数据、地图、人物模型和压缩纹理，无需先下载原始数据。只供本机访问；服务不启动仿真引擎或数据库。

## 第三版——长春

- 保留六处长春特色内容，放大主要地标并抬高体量，周边采用低层生活街屋与集中林地。
- 横贯左右的轻型景观电车高架，跨路段不设桥墩，静态 54 路电车与轨道位置、高度匹配。
- 156 处建筑/展品地块，补齐街区空隙，去除独立白色地台边框，增加院落乔木与灌木。
- 长春道路统一双黄实线与白色车道线，虚实过渡和外围道路连续衔接。
- 建筑布局与桥墩避让全部观测轨迹保护范围，保留四城真实回放、流量、预测与风险分析。

长春特色街区、高架及统一展示标线属于设计表现，不是实测设施复原；电车是静态文化展示，不计入真实交通流量。

## 第二版更新

- 四城真实记录与交通圆环、各方向通过量、流量趋势、风险概览及车辆预测整合首页。
- 车辆按真实观测段淡入淡出；重庆默认隐藏长期静止车辆，可随时切换。
- 增强道路、人行铺装、商铺内部、绿植、建筑入口及街道设施。
- 两套授权骨骼人物覆盖行人、自行车、摩托车及三轮车；新增细化车体、货厢和骑乘姿态。
- 轿车可透视车窗与内部陈设，轮毂远近细节切换、近景阴影聚焦和平滑跟随镜头。

道路与运动来自公开记录；建筑街区、车辆外观和人物装备为设计表现，不是视频重建。四个公开样例不代表完整城市数据。预测与风险属于研究基线，风险指标不是事故概率。完整分析页位于 `/analysis.html`。

## 验证

```bash
npm test
```

浏览器检查需另外安装 Chromium，并设置 `CHROMIUM_PATH` 为浏览器可执行文件绝对路径。启动服务后可运行 `npm run cities:check`、`npm run home:check` 和 `node scripts/check-render-quality.cjs`。截图写入本地 `artifacts/`，不纳入版本。

## 发布精简

保留：代码、测试、必要运行数据、模型 FBX、压缩 JPEG/PNG、授权及来源清单。

排除：node_modules、截图与验收导出、下载分片、可重新下载的原始 CSV、原始 TGA 纹理、Word 附件、日志、数据库及本地环境配置。被排除的已有文件仅取消 Git 跟踪，不删除本机原件。

仅运行系统不需要恢复这些文件。重新开展源数据处理时，可用 `python scripts/download-sind.py` 与 `python scripts/download-sind-public.py` 下载公开样例；模型原文件依据 `assets/characters/rocketbox/provenance.json` 中固定版本与来源恢复。
